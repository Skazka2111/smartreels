# Smart Reels Studio 0.1.0

Первый рабочий прототип настольной программы, которая превращает длинное видео
с речью в набор вертикальных роликов 1080×1920.

## Что уже работает

- локальные MP4, MOV, MKV, M4V, AVI и WEBM;
- проверка исходника через FFprobe;
- транскрибация через собственный OpenAI-совместимый API-ключ пользователя;
- разбиение длинного звука на части и объединение таймкодов;
- кэш транскрибации, чтобы повторный монтаж не оплачивал распознавание заново;
- поиск всех самостоятельных фрагментов выше выбранного порога качества;
- режимы поиска: строгий, сбалансированный и максимальный;
- удаление сильно пересекающихся предложений;
- ручное включение/отключение фрагментов и корректировка начала/конца;
- локальное распознавание лиц анфас и в профиль с помощью OpenCV YuNet,
  отслеживание движения и удержание предыдущего героя при временной потере
  уверенности, включая лица внутри показываемых фотографий;
- ускоренное центрирование при смене говорящего или сцены и аккуратное
  продолжение края кадра, если лицо находится у самой границы исходника;
- три режима вертикализации 1080×1920: умное кадрирование с удержанием героя,
  полное видео на выбранном цветном фоне и полное видео на размытой копии кадра;
- субтитры фразами, с появлением, с подсветкой активного слова и пословным
  pop-up с пружинкой;
- ручное положение субтитров сверху или снизу, увеличенная безопасная зона от
  интерфейса Reels, палитры текста, активного слова, подложки и фона видео;
- готовые варианты оформления: расширенная скруглённая подложка, подложка по
  строкам, рваная бумага, бумажные буквы, обводка, свечение и чистый текст;
  цвет, прозрачность, толщина и размеры настраиваются отдельно;
- выбор шрифта из папки `fonts` и кнопка для добавления своего TTF/OTF;
- отдельные прокручиваемые разделы оформления для видео, субтитров, музыки и
  заставки, отдельная вкладка журнала и видимый номер тестовой сборки;
- музыка с настройкой громкости и плавным началом/завершением;
- короткая конечная заставка, в том числе со своим звуком;
- последовательный экспорт всех выбранных роликов;
- сборочные сценарии Windows x64, macOS ARM64 и macOS Intel.

API-ключи не записываются в настройки или журналы. После закрытия программы их
нужно ввести заново.

## Границы прототипа

Это версия для технической проверки, а не готовая коммерческая сборка.

- Определение героя основано на лицах, непрерывности движения и активности нижней
  части лица. Оно ещё не является полноценной обученной моделью active-speaker
  detection и требует проверки на подкастах с двумя людьми.
- Если лиц не видно, программа использует центр видимого движения; если уверенности
  нет — удерживает прежнее положение, чтобы кадр не прыгал.
- Немые вирусные моменты не ищутся. Фрагменты выбираются только по смыслу речи.
- Ручное указание главного человека, предварительный видеоплеер и YouTube-ссылки
  запланированы после проверки основного конвейера.
- Перед продажей нужны реальные тесты качества, отдельная лицензия продукта,
  обработка отмены и тестирование собранных приложений на чистых Windows/macOS.

## Запуск из исходников

Требования: Python 3.11–3.13 и FFmpeg/FFprobe в `PATH`.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m smart_reels
```

macOS/Linux:

```bash
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m smart_reels
```

## Подключения

Программа использует два независимых OpenAI-совместимых подключения:

1. `audio/transcriptions` — модель транскрибации, возвращающая `verbose_json`.
2. `chat/completions` — текстовая модель для поиска сильных отрывков.

Можно использовать один сервис и один ключ либо разные сервисы. Для анимации
активного слова сервис транскрибации должен вернуть реальные времена слов.
При наличии только сегментных таймкодов программа автоматически использует
субтитры фразами.

## Структура пользовательских данных

При первом запуске создаётся `Smart_Reels_Project`:

```text
Smart_Reels_Project/
├── cache/       сохранённые транскрипции и результаты анализа
└── results/     готовые вертикальные MP4
```

Кэш можно удалить вручную. Исходное видео программа не перемещает и не изменяет.

## Проверка

```bash
python -m pytest -q
python -m compileall -q src
```

Для полноценной ручной проверки нужны действующие API-ключи, FFmpeg с фильтром
`subtitles/libass` и реальные видео с одним и двумя спикерами.
